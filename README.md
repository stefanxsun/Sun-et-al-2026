# Sun-et-al-2026
This repository contains the MATLAB code used to reproduce the analyses and figures for:

**Sun, S. et al.**
*Visual experience drives functional reorganization of cortical GABAergic circuits*


---

## Overview

This repository includes the analysis pipeline used for:

- Two-photon calcium imaging analysis
- Electrophysiology (LFP/MUA) analysis
- Behavioral analysis
- Statistical analysis
- Figure generation
